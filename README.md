# 🥽 Pong Panic VR  

Pong Panic VR is a fast-paced virtual reality reinterpretation of Ping Pong developped on Unity, exclusively for the **Meta Quest 2**. 
Players use a physical paddle to hit a reactive ball in stylized arenas, combining precision, movement, and immersive feedback. 
Designed for VR headsets, the game delivers dynamic matches, intuitive interactions, and a modern twist on a timeless sport.

---

## 🚀 Functionnalities 

- Full VR Immersion – Designed for the Meta Quest 2, delivering intuitive interaction and fast-paced gameplay.

- Dynamic Paddle-Based Mechanics – A modern reinterpretation of Ping Pong with physical motions, precise control, and responsive hits.

- Stylized Low-Poly Aesthetic – Clean, lightweight visuals with unlit rendering for a smooth and comfortable VR experience.

- Interactive 3D Environment – A welcoming lobby space where players can explore, interact with objects, and access game modes naturally.

- Built on Unity XR & OpenXR – Ensures stable performance, broad compatibility, and future-proof VR integration.

## 📂 Files structure  

```plaintext
Assets/
├── Images/ → Sprites and textures
├── Models/ → 3D low poly models (Hands, House, Skins, ...)
├── Scenes/ → Unity Scenes (Lobby, Game, ...)
├── Scripts/ → C# Scripts (inputs, hands, physics)
└── Sounds/ → Musics, sound effects
```
